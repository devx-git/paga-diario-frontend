# 💸 Mi Inversión — Plataforma de Inversiones

Este proyecto es una plataforma de inversión donde los usuarios pueden registrarse, comprar planes, pagar con QR, recibir goteo diario y retirar o reinvertir al finalizar el ciclo.

## 🚀 Funcionalidades principales

- Registro e inicio de sesión
- Compra de planes de inversión (10 niveles)
- Pagos con QR (Nequi y Daviplata)
- Goteo diario automático durante 30 días
- Retiro, reinversión o nueva inversión al finalizar
- Panel administrativo con métricas, usuarios, planes y retiros

## 🧱 Estructura del proyecto

src/ 
├── pages/ # Vistas principales 
├── components/ # Componentes reutilizables 
├── context/ # Contexto de autenticación 
├── api/ # Cliente Axios
